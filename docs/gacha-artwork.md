# 抽卡图片来源与匹配

核验日期：2026-10-18。沿用随程序发布的公开图片目录，网页直接显示官方图片；QQ 图片由既有公开素材缓存下载、校验后提供给同一套组件。

| 游戏 | 已核验来源 | 本次修正 |
| --- | --- | --- |
| 终末地 | [森空岛官方武器图鉴](https://wiki.skland.com/endfield/catalog?mainTypeId=1&subTypeId=2) | 增加页面列出的 84 把武器图片，包括破碎君王、玉中身；按卡池类型区分干员和武器。 |
| 鸣潮 | [库街区公开图鉴接口](https://api.kurobbs.com/wiki/core/catalogue/item/getPage) | 官方角色目录 65 项、武器目录 123 项均有名称映射，补入莉莉和玉阙玄华；补全五星汇总图片及缺少类型时的完整名称查找。 |
| 异环 | [塔吉多公开配队接口](https://bbs-api.tajiduo.com/apihub/awapi/yh/team) | 接口列出 25 个角色，补入明音（1057）；社区统计及 QQ 逐抽账本统一按公开编号、类型和名称查图。 |

终末地页面使用 `/web/v1/wiki/item/catalog`。直接匿名请求返回“设备信息无效”，本次通过无需登录的官方页面读取武器名称和实际背景图片地址，保留完全对应的名称，未生成或猜测游戏物品编号。84 个图片地址均实际取得 200 响应、图片内容类型和 PNG 文件签名。图片只来自已允许的 `bbs.hycdn.cn`，沿用原有网址、文件大小与图片净化限制。

鸣潮目录请求为 POST，表单使用 `catalogueId=1105`（角色）或 `1106`（武器）、`page=1&limit=200`，请求头为 `source=h5`、`wiki_type=9`。图鉴条目编号不作为游戏资源编号。新增两张图片实取正常。异环本地目录的 25 个角色与 50 个弧盘共 75 个唯一图片地址均实取正常；该结果不证明未来新增而尚未收录的弧盘已覆盖。

图片匹配不参与抽数、排序、保底或记录缺口计算。明确的类型限制优先；未知名称保留文字占位。异环名称查找沿用空格、中点、冒号与书名式引号的规范化，只有匹配结果指向唯一图片时才使用。QQ 快照保留 `resource_id`、`resource_type`、`reward_type`，预取也采用对应匹配规则。

新增内容需更新公开目录。更新后同步 `qq/public_asset_catalog.py` 的条目、来源和文件校验值；角色目录变化还须运行 `node scripts/generate-character-search.mjs`，经核实的角色拼音在该生成脚本中维护。图鉴图片目录不会随账号的抽卡数据刷新自动更新。

验收覆盖：真实官方图片加载、终末地最近六星及 QQ 历史图、鸣潮五星栏与第三方汇总、异环角色与弧盘补图，以及失败时保留名称。聊天平台实际送达不在本次检查范围内。
