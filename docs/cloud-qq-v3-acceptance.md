## 用户验收操作

已通过异步问题通知用户，无需重复绑定已有QQ或重新游戏授权：

1. 在已绑定群发送「近期活动」「活动」「日历」「异环 抽卡」，核对游戏范围、日期/来源与完整池顺序。
2. 发送「帮助」「我的总览」及已有角色详情，确认字体、图标、装备速览和长图可读性。
3. 刷新网站，核对桌面/手机导航、各游戏原面板/弹窗、账本/导入工具。导入为本人主动操作，不由代理执行真实导入。
4. 由尚未绑定的朋友用本人网站账号生成码，在允许群发送一次绑定指令；应直接成功，不再回填核对回执。网站密码/游戏验证码/绑定码均不发给代理。

## 保留限制

- 跨群自动复用QQ身份尚未开放，平台身份作用域未充分验证；仍需每群关联，但兑换已简化成一次。
- 终末地所测流程及多人登录已获用户确认；终末地具体授权/能力覆盖范围、真实双向越权拒绝、撤销关联及会话失效、全部新工具来源覆盖仍需分别记录，不能由多人登录成功推定。
- 图标只使用已核实素材；缺图明确占位，不冒用其他图。活动封面是否可得取决于真实来源。
- LCU、桌面截图/OCR、任意本地文件路径不能直接搬到云端；终末地上游签到写操作仍未开放。无新增自定义评分或排名。
- 正常长列表单图；超出资源/平台预算时明确降级，不默默截断。外链仍关闭。
- 新版后若发生故障，保留schema4现场；不能让旧应用直接写schema4，也不能自动覆盖切换后的用户操作。恢复方案以受限运维脚本和迁移前备份为准。
