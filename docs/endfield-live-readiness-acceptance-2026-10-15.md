## 实现结果

| 范围 | 行为 |
| --- | --- |
| 档案与签到失败状态 | 同一角色请求失败时保留原资料、观测和抓取时间，标记旧资料；首次失败保持无成功资料。角色、授权切换与晚响应继续隔离。 |
| 签到 | 本地与云端提供独立 GET 刷新，已签和首次失败仍可重试；手动 POST 保持显式。本期天数仅在每条 `done` 均为布尔值时声明总数，否则保留未知。展示真实 `day`、`signed_at`、奖励及零数量；签后回读失败保留已返回奖励和签到时间。 |
| 概览公告 | 从已有公开快照合并、去重、排序显示最新 5 条，保留来源、旧状态及日期精度；概览摘要不新增采集，提供全部公告入口。 |

| 中文字体和发送桥接 | macOS 中文字体实际执行此前 42 项字体跳过；新增八类终末地报告贯穿真实渲染与模拟上传、被动回复、幂等处理。 |

## 真实接口和视觉验收

用户在本机正常网页登录，隔离服务仅启用终末地、关闭调度，沿用 AES-GCM 加密保存。真实凭据和原始响应未输出或提交；证据目录权限为 0700。

- 档案与独立干员接口 HTTP 200；33 名干员，33 条规范化获得时间，21 份战术道具，6 个舱室、15 条驻守，131 枚奖章。
- 直接编号关联为 0/15，MD5 精确关联为 15/15。修复后新运行时报告的姓名和头像字段均为 15/15；网页实际显示 15 个姓名、15 个图片节点、无内部编号标签。
- 战术效果保留参数占位；网页实际已不显示上述三种游戏色标。一次账号观察不代表所有账号或后续版本必有字段。
- 浏览器验证本地 GET 不签到、已签可刷新、未知不归零、失败保留原时间；模拟提交回读失败显示零数量奖励。云端签到没有提交按钮，读取失败保留旧资料。
- 合成概览验证最新 5 条公告及纯日期不补时分；真实配装在 390px 视口没有横向溢出。云端独立详情使用真实响应包装验证。
