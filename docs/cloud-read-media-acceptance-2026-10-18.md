## 修改

- 初始化请求代际与账号/角色快照代际分离；同账号会话核验保留在途读取，退出/切换仍丢弃旧包。恢复 CSRF 强制核验以兼容跨标签会话轮换。
- 公共错误按能力显示，不再将公共活动/资讯超时统一解释成账号读取异常。授权/会话/日历页不启动无关私有读取，进入已选游戏也立即读数据；公共并发 GET 合并，定时任务不重入。
- 云端成功文本静态资源、公共快照和私有快照在既有鉴权边界内压缩，保留缓存策略；原 Caddy、配置和依赖不修改。游戏面板按需加载，异环使用显式参数契约保留本人快照/角色/作用域。
- B站已核实 CDN HTTP 图规范化为 HTTPS；异环读取结构化 images；同文全文优先级与补图分离，保留图源链接。
- 定向媒体补齐只处理当前版本/活动明确关联、现有官方 UID 的最多 20 条缓存；只写媒体字段，失败保留已有图片；不提高全局解析规则版本或全历史回补。
