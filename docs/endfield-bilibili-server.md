# 终末地 B服绑定

更新时间：2026-10-18。本工具已实现官服/B服渠道选择；真实 B服账号的短信登录、寻访同步和森空岛读取仍需本人验证。

## 绑定步骤

1. 打开[鹰角网络用户中心的角色绑定页](https://user.hypergryph.com/bindCharacters?game=endfield)，登录鹰角通行证。
2. 选择终末地和 `bilibili服`，填写游戏内用户编号（UID），按页面要求取得游戏内邮件验证码并完成关联。
3. 回到本工具的「账号与授权 → 社区账号 → 终末地」，选择「B服」，用刚才的鹰角通行证手机号短信登录。
4. 核对授权列表中的「B服」标签，再同步寻访记录或连接森空岛档案。

同一通行证同时有关联的官服和 B服角色时，本工具只选择本次指定渠道的角色，优先采用上游默认角色。选择 B服却没有可用角色时会提示先完成官方关联；不会悄悄改登官服。

## B站资讯授权与游戏绑定

管理员公共源面板的登录凭据（SESSDATA）只用于 B站公开资讯采集，不能用来绑定终末地 B服，也不能代替鹰角短信登录。

公共源必须通过 B站身份验证后才会加密保存。验证失败会保留原授权；页面区分凭据失效、风控限制、响应异常和无法确认保存结果。请求中断后，可先检查授权会话或刷新授权状态，无须重复粘贴凭据。只有服务器明确返回未配置时，页面才显示未配置。

## 账号与数据边界

- 官服的渠道编号是 `1`，B服是 `2`；这不是服务器编号。当前寻访接口的国服服务器编号仍为 `1`。
- 渠道在开始短信会话时固定。切换渠道会清除前端旧会话；提交登录时不能改写该会话的渠道。
- 后续账号与寻访读取核对保存的账号、角色、服务器和渠道。默认角色改变时，不会把另一角色的数据写入原账本。
- 云端账号与角色按渠道分别保存；手动森空岛返回的渠道不明确时，显示「渠道未提供」，不填成官服。
- 一键连接森空岛及续期必须匹配父授权的完整身份。上游未返回可信渠道、角色未关联或身份不一致时，连接失败并保留原授权，可改用手动森空岛授权。手动授权保持独立。
- 旧官服授权保留兼容。曾被旧版本标成官服的手动森空岛记录，重新核验为 B服后会建立正确的渠道记录，旧记录不再提供角色读取；不复用或重标旧角色的数据目录。
- 云端继续只读游戏数据，不执行签到。真实账号凭据不会写入文档、截图或验证报告。

## 核验依据与范围

2026-10-18 实际读取的[鹰角官方游戏目录](https://binding-api-account-prod.hypergryph.com/general/v1/auth_app_list)列出了终末地官服与 `bilibili服`；官方账号中心当前页面使用用户编号和游戏内邮件验证码完成关联。早期调研中「通过 B站账号授权」及「必须模拟设备指纹」的说法不再作为当前实现依据。

自动化检查使用合成角色和模拟上游响应，覆盖纯 B服、混合渠道、删除/封禁角色、未知或矛盾渠道、身份改变、云端用户隔离、旧授权兼容、派生授权失效和公共源保存状态。浏览器检查使用合成数据；这些检查不代表真实 B服账号已绑定成功。

真实账号验收应依次确认：官方关联成功 → 短信登录返回 B服角色 → 授权列表标签正确 → 寻访同步入库并在刷新后可见 → 森空岛档案与同一角色一致。上游拒绝或没有返回的数据，应保留明确错误和缺失状态。
