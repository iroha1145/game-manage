# QQ 官方文档核对记录

核对日期：2026-10-17。对象为当前分支的 QQ 接入、图片上传、被动回复和账号绑定。
本记录区分代码检查与运营条件，不代表腾讯审核通过，也不代表游戏素材已获使用授权。
本次没有登录机器人管理后台、读取生产凭据、部署或发送真实 QQ 消息。

## 接口与代码

| 项目 | 官方依据 | 当前实现与处理 |
| --- | --- | --- |
| 图片上传文件名 | [群聊上传](https://bot.q.qq.com/wiki/develop/api-v2/autogen/api/v2_groups_group_openid_files.post.html)、[单聊上传](https://bot.q.qq.com/wiki/develop/api-v2/autogen/api/v2_users_user_openid_files.post.html)，2026-10-09 更新 | 二进制上传必须带 `file_name`。已补齐，按通过解码验证的格式使用 `reply.png` 或 `reply.jpg`，不含账号或角色标识。 |
| 图片格式与体积 | 同上 | 只接受静态 PNG/JPEG；默认 512 KiB，配置上限 1 MiB，连同 Base64 编码仍小于文档的 5M 直传限制。没有使用文件路径或任意网址自动上传。 |
| 上传与发送分离 | 同上及[富媒体消息概述](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/rich-media.html) | 上传保持 `srv_send_msg=false`，返回后透传 `file_info`，再以 `msg_type=7` 回复。群与单聊各用对应接口；不缓存平台 `file_info`，每次重新上传。 |
| 被动回复 | [消息概述](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)、[群消息接口](https://bot.q.qq.com/wiki/develop/api-v2/autogen/api/v2_groups_group_openid_messages.post.html) | 统一采用 5 分钟内、每条指令最多一次回复，携带原 `msg_id` 和 `msg_seq=1`；严于消息概述的群聊 5 分钟 5 次、单聊 60 分钟 4 次。单聊参数表仍有旧的 5 分钟描述，当前实现同时满足这两种时限。 |
| 翻页与失败处理 | 同上 | 每条指令只发送所选的一页，不自动连发。上传失败且仍在期限内才回退文字；最终消息发送结果不确定时不补发。持久化去重在重启后仍生效。 |
| 事件订阅 | [事件与权限](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/event-emit/payload.html)，2026-07-21 更新 | 官方要求订阅范围与业务匹配，无权限的订阅可能使连接被关闭。锁定依赖原先还订阅频道与互动事件；现仅设置群聊/单聊共用的 `1 << 25`。单聊处理仍默认关闭，群聊仍检查允许名单。 |
| 接口地址与鉴权 | [鉴权说明](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/interface-framework/api-use.html)，2026-07-30 更新 | 保留当前 `api.bot.qq.com` 接口和凭证地址，以及 `Authorization: QQBot …`。不因旧版依赖或旧文档使用其他域名而改回旧地址。 |
| 调用频率 | 上传页为 50 次/秒；[群消息接口](https://bot.q.qq.com/wiki/develop/api-v2/autogen/api/v2_groups_group_openid_messages.post.html)为 100 次/秒 | 增加上传、文字和图片消息共用的 50 毫秒调用间隔。独立机器人进程内的调度仍串行执行；等待前后都检查回复期限。此限制不跨进程共享，同一机器人不能靠启动多个实例扩大额度。 |
| 错误响应 | [接口调用指南](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/api-call-guide.html) | 日志优先读取新版 `err_code`，兼容旧 `code`；仅记录有效整数和 HTTP 状态，不记录响应正文、身份标识或追踪数据。 |

对应实现：[接入客户端](../src/game_assistant/qq/client.py)、[消息调度](../src/game_assistant/qq/transport.py)。
软件开发工具包（SDK）仍锁定 `qqbot-agent-sdk==1.2.2`。该版本没有订阅参数，
因此在加载时修改其 `websocket` 模块实际读取的常量；测试捕获该依赖生成的登录帧，
防止只修改无效的导出副本。更新依赖时应重新核对这项适配。

720×1440、22 像素以上的辅助文字、项目内部像素与字节限制，均是本项目为阅读和资源使用设定的约束。
本次读取的上传与消息接口没有给出统一图片分辨率上限；不能把本项目尺寸称为官方要求。
同样，项目的文字长度上限不是官方保证所有消息都能通过的数字。

## 仍需运营者核实的条件

下列要求来自[官方接入说明](https://bot.q.qq.com/wiki/)和[平台运营规范](https://bot.q.qq.com/wiki/business/)。
后台配置和授权材料无法由本地代码测试代替。

- **后台状态**：确认审核、发布状态、目标群及群聊/单聊权限；核对生产地址白名单。项目默认不发送网址，日后开启链接时须核对消息域名配置。
- **游戏素材权利**：本次检查的第三方说明和素材来源记录未提供使用授权证明。能从官方页面下载图片不等于取得使用许可；游戏标识、角色、武器和公告图片仍需按实际用途核实权利和审核材料。
- **个人信息**：绑定前已补充所存标识、使用目的、群内可见范围和解除关联的效果。尚未核实运营者的公开联系方式、既有用户告知/同意记录，以及删除申请的实际处理流程。
- **数据删除**：当前解除关联只是撤销查询权限，仍保留关联记录；不能把它称为删除数据。需另行验证用户删除申请和停运清理能覆盖身份关联、缓存、日志及相关备份。
- **功能与内容审核**：网站绑定的使用条件、抽卡历史和卡池公告的展示范围，应如实申报并以平台审核结果为准；昵称、公告等内容的投诉与处置流程尚未验收。

公开来源说明见 [第三方素材说明](../THIRD_PARTY_NOTICES.md)；绑定提示见
[QqBindingPanel.vue](../frontend/src/components/QqBindingPanel.vue)。这些说明没有替代授权证明或用户数据删除流程。
