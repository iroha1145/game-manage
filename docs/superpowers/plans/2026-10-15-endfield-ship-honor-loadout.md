# 帝江号、光荣之路与战术道具

日期：2026-10-15。基线：`02a16e9`。延续终末地网页与 QQ 报告迭代；蓝图扩展、生产计算器、互动地图、Wiki 与养成、MaaEnd 远程控制继续暂缓。

## 已核验的差距与依据

- 帝江号原始 `physicalStrength`、`favorability` 已保存，当前网页和 QQ 只显示原数值。[公开插件 API 文档](https://github.com/Entropy-Increase-Team/endfield-plugin/blob/main/API.md#L6089-L6123) 明确给出心情 0～10000、信赖分段换算及阶段。这是可注明来源的参考模型，不能据此声称当前游戏实时状态。
- 房间 `lastReportTs` 与抓取时间不是同一基准；公开文档的 constants/relationLevels 属于第三方派生数据，不能称为官方 card/detail 的配置。本轮只换算快照，不启用时间外推。
- 奖章 `achievementData.cateName` 有 `/achieve` 完整透传 `detail.achieve` 的公开文档依据；原始奖章已保存，现有报告遗漏分类。
- `/card/char` 文档明确战术道具 `tacticalItem` 与嵌套 `tacticalItemData`，原站公开解析也消费该字段；当前统一解析丢弃。干员 `ownTs` 目前仅找到聚合 note 示例，获得时间先不套用到原始干员响应。

## 实施范围

1. 共享报告为驻守干员添加 `mood_percent`、`trust_percent`、`trust_level_name`，保留原值和原观测时间，记录换算模型来源。心情在声明范围内按原值 / 100 换算；信赖按文档向下取整并在 200% 封顶。缺失、非法值与超范围心情仍为未知；零有效。网页和 QQ 采用一致的至多一位小数显示。
2. 网页帝江号显示心情条、信赖阶段与百分比，保留原始值入口；兼容无 report 的旧 payload、只有原值的旧 report 和新报告。旧快照无需迁移或新增上游请求。
3. 共享奖章增加分类；网页提供分类、名称搜索、获得时间排序和清晰的筛选结果数量；缺分类仍可见，不猜未获得奖章。QQ 按分类整理并明确已显示数量，保持图片预算与文字回退。
4. 统一干员解析增加可选 `tactical_item`，只投影核验过的名字、稀有度、图标和效果字段；网页配装与 QQ 干员图片同步展示。缺字段和旧快照继续可读，不猜测获得时间。
5. 顺手补齐已有字段的呈现：主线进度、已满理智快照文案、旧地区收集名称及包含年份的资料时间。
