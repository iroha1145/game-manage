# 终末地看板与 QQ 视觉迭代

日期：2026-10-15。基线：`0088cbd`。本轮实现、自动化回归和合成视觉验收完成，实际 QQ 送达待运行环境验证。本轮延续已批准的终末地网页与 QQ 目标。

## 目标与证据

对照 `../endfield-research/01-站点外壳与设计系统.md`、`02-森空岛绑定与账号数据看板.md` 及桌面/手机截图，第一期的六报告已有数据和基本排版，正式界面仍有以下差距：

- 正式 Dashboard 的九个同级页签与两张账号大卡占据首屏；此前独立 Reports 预览未覆盖这一层。
- 网页和 QQ 的圆角卡片、重复人物头像、大块缺图占位使终末地的工业风层次不够清楚。
- 光荣之路只展示数量，未使用已保存的完整奖章列表。
- 网页配装详情遗漏独立抓取时间；寻访同步在未扫描后续卡池时可能误报完成。

用户暂缓的蓝图扩展、生产计算器、互动地图、Wiki 与养成、MaaEnd 远程控制继续排除。原有工具入口保留兼容。本轮不复制原站品牌、Logo 或源代码，不引入第三方账号代理。

- 官网 `https://endfield.hypergryph.com/`，公开 chunk `6753-58bf72aace2b00ef.js` 明确使用 `avatar:D`、`portrait:T` 映射。目录按完整官网 key 或唯一中文名匹配，未猜游戏 ID 后缀，不为泛名“管理员”猜性别。
- 2026-10-15 查看佩丽卡与祀的公开人物 PNG（303×386），以此替换详情中放大的120像素头像。QQ 普通素材仍缩至192像素，只有审查目录内的 portrait 可保留到512像素，沿用2MiB下载、400万源像素、公共域名与地址校验和总缓存限额。
- 勋章字段来自研究原始 capture `0c6abe53f5cd1492.js` 的奖章列表显示逻辑：`achievementData.id/name/initIcon/reforge2Icon/reforge3Icon/platedIcon`、`level`、`isPlated`、`obtainTs`。仅重写字段投影，不复制组件实现。不采用原站仅显示10项的截断；资源超限则明确说明。
