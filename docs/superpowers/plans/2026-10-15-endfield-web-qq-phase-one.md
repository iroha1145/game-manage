# 终末地网页与 QQ 第一期实施计划

日期：2026-10-15。状态：第一期实现、自动化测试与本地视觉验收完成；真实 QQ 送达待部署后验证。

## 目标与范围

在 game-manage 现有终末地直连、云端账号和 QQ 图片能力上，完善六种日常报告：总览、单干员详情、全员练度、地区建设、帝江号、寻访战报。网页与 QQ 共用数据含义、统计口径与来源状态，分别采用适合交互和聊天阅读的布局。

用户明确暂缓：蓝图库与蓝图分享、生产计算器、互动地图、Wiki 与养成规划、MaaEnd 远程控制。本期不扩展这些功能，已有入口与功能保持兼容。

后续候选包括挑战与光荣之路展示、长期个人变化记录、理智及活动订阅提醒、规则可核验的寻访预算与模拟。后续候选不作为本期验收前提；不新增付费订阅、公共社区、国际服或开发者平台。

## 设计与工程约定

1. 继续使用 FastAPI、Vue 与 Pillow。以终末地领域展示函数整理字段，网页和 QQ 通过可测试的结构消费，避免模板内散落未经解释的上游字段。
2. 原始观测时间、抓取时间和渲染时间分清；缺失值保持未知，零和 false 保留。成功空列表与未采集分开。
3. 主账号授权、森空岛会话、鹰角寻访身份不默认等同。仅在角色及服务器等身份有明确证据时关联；否则分别显示，不跨账号拼装报告。
4. 账号切换、撤销授权、晚返回请求与图片缓存沿用现有隔离和复核。新图片类型必须进入原有安全显示文档与素材机制。
5. QQ 使用终末地专用的中文信息层级、黄主色和青辅色。正常查询一张完整长图；资源超限明确说明，不静默截断或无限缩字。图片保留来源和更新时间。
6. 素材优先使用来源可核验的公开上游地址和稳定资源 ID，纳入现有来源校验、公开缓存、尺寸/类型/体积限制。缺图采用真实名称与原创占位，不加载任意 URL，不复用认证请求头。
7. 不新增上游写操作、自动签到或 QQ 主动消息。开发验证不触发真实账号登录、刷新或群消息。
8. 本期不部署或合并到远程主分支。交付可审查的开发分支、测试证据及合成图片预览。

- 六类报告在网页与 QQ 均有可用入口，共用同一账号观测数据，不要求为 QQ 重复登录。
- 本机一键森空岛连接继续可用；云端不访问本机全局凭据，也不跨用户拼接。
- QQ 专项图片完整、文字可读、缺图明确；默认预算沿用现有 1080 像素宽、1600 万像素、1 MiB 和渲染超时约束。
- 真实上游来源尚未证明的图片/公式保留限制说明，合成数据不冒充真实账号或实际送图验收。
- 自动化用例、两种构建与图片视觉检查通过；真实 QQ 送达由用户在现有环境主动发出指令后验收。
