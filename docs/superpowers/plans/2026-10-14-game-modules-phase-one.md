## 全局约束

- 首批游戏为鸣潮、异环；共享组件改动须保持其他游戏正常使用。
- 数据来源、版本、读取时间与完整性独立记录；未知、未配置、不可评分和真实零值分开。
- QQ 只渲染当前请求已获授权的数据；浏览器不继承运营者或其他用户登录会话。
- 图片复用网页内容组件和设计变量；允许展示模式差异，不另建同内容的 QQ 模板。
- 保留已有缓存隔离、授权撤销和错误处理契约；缓存键包括身份范围、授权版本、数据指纹、组件版本与展示模式。
- API 已装备配置不当作完整库存；第三方抽卡摘要不当作逐抽流水。
- 上游代码、公式、权重和图片分别核验来源与使用条件；不直接执行远程评分包。
- 外部接口真实可用性、QQ 发图结果、真实 OCR 与本地测试分别报告。
- 所有排行榜功能明确不考虑：不开发、不接入、不扩展群榜、全国榜、评分榜或其他用户之间的排名；同一角色两套配置的个人比较保留。
- 提醒细化与攻略/角色搜索统一纳入第一批；原第二批的其他功能全部明确暂不考虑，不再作为待排期功能。

## 重点核验

1. 跨月版本、版本中途更正及下半版本活动不得被自然月筛选或缓存遗漏。
2. 缺少版本结束时间、活动时刻或某来源失败时仍展示已知条目，并明确覆盖限制。
3. QQ 图片任务遇到换号、授权撤销、同群不同用户并发时不得串数据。
4. 字体/图片加载超时、超长日历、浏览器崩溃时不得发空图、半图或截断活动。
5. 评分模型更新和抽卡覆盖变化不得制造虚假提升或精确保底。
