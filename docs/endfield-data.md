# 终末地数据展示与来源

在「社区账号」用鹰角通行证手机号登录终末地（目前只支持官服），然后从左侧进入「终末地」，点击「刷新数据」。

2026-09-28 已扩展为[终末地工具箱](endfield-toolbox.md)。官网公告、地图目录与点位已实测；2026-10-14 又用官服真实账号验证了鹰角短信登录、寻访同步和森空岛读取，签到提交尚未实测。

| 区块 | 来源 | 展示口径 |
| --- | --- | --- |
| 账号概览 | 通行证授权 → `binding_list?appCode=endfield` | 官服角色昵称、等级、服务器、渠道；角色变化时提示重新登录 |
| 寻访记录 | 通行证授权 → `u8_token_by_uid` → `ef-webview.hypergryph.com/api/record/*` | 按卡池统计总抽数、6★/5★ 数量、距上次 6★ 的抽数、6★ 历史；逐条记录可分页查看和导出 |
| 资讯 | 终末地官网；没有官网快照时回退 B站官号 `明日方舟终末地`（UID 1265652806） | 保留真实来源和同步状态 |
| 活动日历 | 官网全文版本说明与寻访说明 | 见下文“公告解析” |

理智、每日活跃、协议通行证、干员练度、地区探索、帝江号、挑战和签到使用森空岛数据。登录鹰角通行证后，可在终末地概览一键连接森空岛并自动选中同一角色；也可以手动粘贴自己的官方会话。程序不会伪造设备指纹。地图检索与蓝图收藏无需账号，详见工具箱说明。

## 寻访记录

- 官方记录页明确说明可查近 90 日，结果约有 30 分钟延迟（2026-09-28 核对官方前端脚本）。本工具从第一次同步开始，把记录保存在数据库旁的 `*.endfield-gacha.sqlite3`，按角色隔离；退出登录不会删除账本。
- 同步以 `seqId` 去重。每次最多请求 120 页（每页 5 条，页间隔 0.3 秒）；首次同步没翻完的部分会记为待续传区段，下次「刷新数据」或 4 小时一次的自动同步接着翻。
- 翻到官方窗口尽头仍没接上本地更早的记录时，记为永久缺口（例如超过 90 天没同步）。
- “距上次 6★”只在连续记录中给出确定值；跨过缺口，或统计范围里有免费寻访（是否计入垫抽尚未核实）时，显示“至少 N 抽”；没有记录时显示未知。不内置保底数值，也不判断是否“歪”。
- 目前查询五种角色池类型：特许寻访、重构寻访、基础寻访、启程寻访、辉光庆典；武器池按接口返回的池列表逐个查询。重构寻访类型由官方记录页核实。未来新增类型仍需在 `adapters/endfield/endpoints.py` 的 `CHAR_POOL_TYPES` 中补充。
- u8_token 只在单次同步中使用，不写入磁盘或日志；导出文件不含任何凭据。

### 寻访分析页

2026-10-19 参照社区抽卡分析页的结构重排，统计口径不变：

- 干员寻访与武器申领是不同的货币和概率，任何位置都不相加。分析页顶部分成「干员寻访」「武器申领」两块，各显示抽数、6★、5★ 和平均出 6★；缺口与免费寻访的说明收进同步状态旁的 ⓘ。终末地概览的寻访摘要同样分两行；首页「抽卡概况」只统计干员寻访，并标明范围。
- 卡池选择按类型：特许寻访、重构寻访、辉光庆典、基础寻访、启程寻访各一张，所有武器申领合为一张。干员类型显示「已垫」，武器显示最新一期的「当期已垫」。点选后逐条记录的卡池筛选同步切换；手机上为一行横向滑动。
- 详情先给该类型合计：已垫、总抽数（含免费数）、6★、5★、平均出 6★、最欧、最非和稀有度占比条；再「按期统计」，每期（官方 poolId）单列抽数、6★、5★ 和本期的 6★ 出货横条，本期未出 6★ 时注明。只有一期的类型不再分期。
- 账本按同一卡池类型连续计数，所以干员 6★ 的抽数可能包含上一期的垫抽，分期只拆计数、不另算已垫；武器每期本来就是独立账本池，各期显示自己的已垫。
- 平均、最欧和最非只取已展示历史中抽数准确的区间；只有两个以上不同的准确区间才标最欧 / 最非。每期 6★ 数多于已展示历史时注明「另有 N 次不在已展示的历史中」。
- 横条按同类卡池（干员或武器）中最长的一次 6★ 取整到 10 抽作标尺，只用于比较，不代表保底；下限区间用斜纹。稀有度沿用游戏习惯：6★ 橙、5★ 金、4★ 紫。逐条记录每行带干员或武器图标。
- 每期计数由账本同步时生成（`banners` 字段）；更新前保存的快照在下次同步前只能按 6★ 所在卡池分组，期内抽数显示未知。
- QQ「寻访战报」长图依次列出每个类型及其各期，6★ 为三列卡片；超出图片限制时仍整体回退文字摘要。
