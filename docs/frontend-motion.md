# 前端布局与动效

2026-10-17 第二轮把界面从头重做：浅灰画布上放白色卡片，侧栏和顶栏是浮在页面上的毛玻璃，卡片大小混排（便当盒式布局），加入图表、原创主视觉、横向滑动的卡片行、滚动出现和视差。页面结构、数据含义和文案规则不变，变的是视觉层。深色主题是单独调过的一套颜色，不是把浅色反过来。

## 表面

- **画布与卡片**：浅色主题画布 `--bg #f3f4f7`（偏冷的浅灰），卡片纯白 `--card-bg`，一圈很淡的细线 `--card-border` 加柔和的分层阴影 `--card-shadow`。可点的卡片悬停时上浮 3px，阴影换成 `--card-hover-shadow`，按下缩到 0.98。卡片里面的分组用一层底色台阶 `--surface-soft`，不再套带边框的框。
- **毛玻璃**：只给浮在内容上方的东西用：侧栏、顶栏、下拉菜单、横滑行的箭头、主视觉上的按钮和标签、日历的日期表头。配方在 `:root` 里：`--glass-bg`（白 64%）、`--glass-filter`（模糊 24px、饱和度 180%）、`--glass-border` 和顶部高光 `--glass-edge`。卡片本身保持实色，保证文字对比度和滚动性能。画布四角有很淡的彩色光晕（`--ambient-*`），给毛玻璃一点可以模糊的颜色；支持滚动时间轴的浏览器里，光晕比页面滚得慢。
- **圆角**：外壳 28px（`--radius-shell`）、卡片 24px（`--radius-card`）、卡片内的小块 18px 或 14px（`--radius-tile`、`--radius-well`）、输入框和小控件 12px（`--radius-control`）。按钮、标签、徽章、分段控件都是胶囊形（999px）。从外到内逐级变小。
- **阴影**：静止的卡片有柔和阴影，浮层（菜单、弹窗、提示）阴影最重。被强调的那一张卡片可以带一层自己游戏颜色的光晕阴影。

## 颜色

- **每个游戏两种颜色**：`--game-wuwa` 等是“墨色”，能当文字用（对比度不低于 4.5:1）；`--game-wuwa-vivid` 和 `--game-wuwa-2` 是鲜艳的一对，只用于填充、图形、图表和主视觉，不当小字的颜色。`gameStyle(id)` 同时给出 `color`、`vivid`、`vivid2`，游戏页根元素上有 `--game-accent`、`--game-vivid`、`--game-vivid-2`。
- **一屏一个饱和色块**：每一屏只有一张卡片用饱和的渐变（总览的“最近截止”、游戏页顶部的主视觉横幅）。其余卡片是白色，分类卡片用游戏颜色的浅色调。饱和色还用来标出“当前”的那一项（选中、最新、即将截止）。
- **图表色**：`--chart-1` 到 `--chart-8` 按固定顺序取用（蓝、橙、青绿、黄、品红、绿、紫、红），这个顺序用 dataviz 的校验脚本在白色卡片 `#ffffff` 和深色卡片 `#18191d` 上都检查过色盲可分辨度。只有一个系列时用游戏的鲜艳色。颜色跟着对象走，筛选后剩下的系列不换颜色。
- **文字**：正文与说明用 `--text`、`--text-body`、`--text-muted`、`--text-faint`，在所有卡片底色上都不低于 4.5:1。状态色（成功、失败、过期）只表示状态，总配文字说明。

## 文字

- 系统字体（苹方、Segoe UI、微软雅黑）。页面标题 30px/600，区块标题 17px/600，卡片标题 16px/600，正文 13～14px/400，说明与标签 12px。12px 是下限。
- 关键数字 28～44px、字重 600、字距 -0.02em 到 -0.04em，用比例数字（`font-variant-numeric: proportional-nums`），单位缩小到约 55%～60% 跟在后面。表格、坐标轴和需要竖向对齐的数字保持等宽数字（全局默认）。

## 布局

- **外壳**：侧栏是离窗口边缘 12px 的毛玻璃浮板，顶栏同样浮在内容上方并随页面吸顶。手机上侧栏变成抽屉，顶栏留 8px 边距。
- **便当盒**：总览顶部是“主视觉 + 最近截止 + 未来 7 天截止”三块，下面是四个游戏卡、横向滑动的活动卡和两列资讯。游戏页先是主视觉横幅，再是标签页，标签页里用大小不同的卡片组合，不再是一列同样的灰盒子。
- **横向滑动**：可以横着浏览的一组卡片用 `HRail.vue`：吸附滚动，边缘渐隐，内容超出时才出现左右箭头（精确指针才显示），可以用键盘聚焦后滚动。机器人图片里改为换行排开。

## 图表

图表是手写的 SVG 或 CSS 组件，没有引入图表库。规则来自 dataviz：

| 组件 | 用途 | 要点 |
| --- | --- | --- |
| `RingGauge.vue` | 体力、进度、胜率 | 圆角端点，`role="meter"` 带数值；数值未知时只画轨道 |
| `BarChart.vue` | 每天、每期、每类的数量 | 柱宽不超过 24px，只在数据端圆角；只给最高的和强调的那根标数字，其余在悬停或聚焦时显示；未知值保留位置并写“未知” |
| `TrendChart.vue` | 随时间变化的数值 | 2px 平滑曲线（单调插值，不会冲过数据点）和渐变面积，末端圆点加数值，悬停或方向键移动十字线 |
| `DonutChart.vue` | 占比（不超过 6 份） | 份与份之间留 2px 缝；两份以上一定有图例，图例写数值和百分比 |

每个图表的数值不靠悬停也能读到：直接标签、图例，或者给读屏器的列表。图形的颜色从不用在文字上。

## 图片与主视觉

- 仓库不带任何官方美术资源。主视觉用 `GameArt.vue` 画原创的几何图形：总览是四个游戏颜色的星球轨道，鸣潮是声波和波纹，异环是交错的光环，英雄联盟是六边形格子，终末地是工业网格和三角。图形分成几层，配合视差移动。
- 角色、物品等图片只来自现有数据和图标目录里的地址，不新增图片来源。离线或图片加载失败时显示带底色的首字方块，设计上要让这个兜底样子也像有意为之。

## 动效

- **滚动出现**（`v-reveal`）：默认可见。只有页面首屏以下、浏览器支持 IntersectionObserver、没有开启减少动态效果、也不在机器人图片里的元素，才先藏起来等滚到再出现。出现时上浮 20px、模糊 3px 到清晰，透明度 500ms、位移 600ms，一起出现的卡片依次错开 60ms；结束后去掉标记，把悬停和按压动效交还给卡片。卡片里带 `t-draw` 的图形（圆环、柱子、曲线）跟着卡片一起开始画。
- **视差**（`v-parallax`）：给容器写入 `--plx`（离视口中线的距离，-1 到 1），里面带 `plx-layer` 的图层按各自的 `--plx-range` 位移。只用 transform，一个滚动监听服务所有图层，每帧最多计算一次。
- **其他**：数字变化时轻微上浮（`v-pop`），标签页的滑块（`v-glide`），总览卡片跟随指针的高光（`v-spotlight`），主题切换的圆形展开。时长、缓动、距离、缩放都用 `motion.css` 里的 transitions.dev 变量。
- **减少动态效果**：系统开启后，全局关闭动画和过渡，滚动出现和视差都不启用，内容直接显示。
- **机器人图片**：`render.css` 让滚动出现的元素直接可见，取消视差位移、毛玻璃和横滑，图片里的内容不依赖悬停、滚动或动画。

## 文案

按“删掉一半的字，再删掉剩下的一半”处理说明性文字，只保留界面本身看不出来的信息：数据状态与陈旧提示、数据来源、估算口径、时区（每页一次，写“北京时间”）、不可撤销操作的后果、输入凭据处必要的一句安全说明、出错后下一步怎么办。页头不配复述标题的说明句，正常状态不写安抚话，导航名与页面标题一致。测试里写明要保留的说明句（海克斯的样本胜率、终末地挑战记录的完整性、连接森空岛的提示、机器人公告图的摘要说明、机器人日历图的标题、QQ 群的管理范围、已有授权保留）不删。

## 交互约定

- **导航与标签**：选中背景在独立图层，文字和图标始终在上方。侧栏选中项是一块白色胶囊加轻阴影，游戏项里有一条该游戏颜色的短竖条。窄屏标签条在选择变化或容器变窄时，把被遮住的选中项滚进视野，不打断用户手动浏览。
- **详情弹窗**：鸣潮与异环保留各自的居中弹窗。打开约 250ms，关闭约 150ms，位移 8px；关闭动画结束后才移除弹窗、解锁滚动并恢复入口焦点。动画事件缺失时 220ms 后仍会完成关闭；组件提前卸载会取消等待。
- **活动日历**：上方三个计数（进行中、3 天内截止、未开始）和各游戏占比；时间轴每条活动 32px 高，圆角色条用游戏的鲜艳色，已过去的部分更深；日期表头吸顶并有毛玻璃效果；今天用实心胶囊和一条竖线标出。关闭详情或按 Escape 后，焦点回到原活动。
- **动画范围**：动效绑定到用户操作、内容变化或滚动到达；首屏内容不等待动画即可阅读。卸载时清理观察器、事件和待执行帧。

## 验证

在 `frontend` 运行 `npm test` 和 `npm run build`。持续集成用 Node 22，本机若是更新的 Node，要另用 Node 22（`/usr/local/bin/node --test src/*.test.js src/components/*.test.js`）跑一遍。DOM 回归覆盖导航层级、横向滚动、滚动出现（只隐藏首屏以下的卡片，机器人图片和减少动态效果下不隐藏）、视差（每帧一次、最后一个图层卸载后停止监听）、横滑箭头、弹窗关闭与卸载清理。机器人图片的真实渲染测试需要先用 `scripts/cloud/build_frontend.py --frontend frontend` 构建，再设置 `QQ_RENDER_TEST_EXECUTABLE` 和 `QQ_RENDER_TEST_FONT` 运行。

浏览器检查覆盖桌面和手机宽度、日夜主题、模态弹窗、Escape、焦点恢复和横向溢出；它验证界面行为，不依赖私人游戏账号。
